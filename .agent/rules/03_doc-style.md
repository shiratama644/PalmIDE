# Rule 03: ドキュメント記述スタイル（new/ 編集時の書式）

> 優先度: HIGH（可読性の一貫性を保つ）

## 1. 言語と表記

- 本文は**日本語**。コード識別子・技術固有名詞は英語のまま
- 「〜です/ます」調。実装前叩き台の表現は「〜する」「〜とする」主体の断定形
- 絵文字は既存ファイルのパターンにのみ従う（# 行頭の `# 📚` / `# 📐` 等）。新規の飾り絵文字は増やさない

## 2. ファイル構成テンプレート（new/NN_*.md）

```markdown
<!-- 統合版: ... -->
# NN 章タイトル

> **親ドキュメント**: [Local_AI_Agent.md](../uploads/Local%20AI%20Agent.md)（§X）
> **インデックス**: [README.md](./README.md)
> **関連ファイル**: [NN_xxx.md](./NN_xxx.md)（関係）

> **要約**: 本ファイルは〜を定義する。

> **ナビゲーション**: ← [前章] | [次章] →
---

## 章番号. 本文…

（章番号は Local_AI_Agent.md の元の番号に合わる）
---

> **出典**: …統合版である。
> **相互参照**: …
```

## 3. リンク規約

- `new/` 内の相互リンクは **`./NN_名前.md` 形式（同一ディレクトリ相対）**
- 親参照は `../uploads/Local%20AI%20Agent.md`（スペースは `%20`。`Local_AI_Agent.md` というファイル名は存在しないため絶対に使わない）
- ルート README 参照は使わない（統合版 README は `./README.md`）

## 4. 参考書書式

- 表: ヘッダ・アラインメント行・本文の3行以上。単価・期間は `1.50` / `2週間` など単位を明記
- コードフェンス: ` ```typescript` / ` ```text` / ` ```markdown` など言語タグ必須。ASCIIアート図は `text`
- 節番号: `## 5.` / `### 5.1` / `### 5.1.1` の階層を厳守（既存の章番号を keep）
- 新しいサブセクションを追加するときは、既存節の直後に `.N` 番として割り込ませる（例: `### 3.1.1`、`## 11.1`）

## 5. ASCIIアート図の編集方針

- **2層Sandbox（02 §2.1）は決定済み**。新しい図を追加する場合は枠幅を揃え、既存欄の `空欄は全角ぶん詰める` スタイルに合わせる
- 図の中で「←」や「→」で別ファイル参照を書く場合は崩れない範囲で。複雑なら図の直後に文章で補う

## 6. 出典・履歴の記法

- `> 🆕` / `> ⚠️` 引用ブロックは**使用禁止**（旧形式、統合版で解体済み）
- 変更の履歴は Git commit / `MERGE_DIFF_REPORT.md` 式のレポートで残す（本文中には残さない）
